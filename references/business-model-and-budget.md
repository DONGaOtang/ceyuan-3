# 经营模型与预算

本文件用于 Step 3 经营模型、Step 6 交付系统、Step 8 成案。目标是让活动的“钱、资源、回报、降级”说得清。

## 一、触发条件

命中任一项必须加载：

- 用户提供预算、报价、成本、收入、ROI、赞助、票务、销售线索、订货、GMV。
- 乙方提案、招商赞助、老板过会、年度项目、大型活动。
- 用户问“为什么值”“怎么省钱”“预算怎么分”“钱花在哪”。

## 二、成本模型

| 成本类型 | 包含 | 输出要求 |
|---|---|---|
| 固定成本 | 策划、设计、场地基础、基础搭建、基础 AV、项目管理 | 不随人数变化，先锁不可砍项 |
| 可变成本 | 餐饮、礼品、座位、胸卡、物料、人员加班 | 按人头或数量计算 |
| 半可变成本 | 摄影摄像、传播、嘉宾、安保、搭建升级 | 给档位或区间 |
| 应急金 | 天气、供应商、物料损耗、临时加项 | 按风险估算且注明计提基数；10%仅为可选显式假设 |

所有金额必须标来源：用户给定、供应商报价、历史数据、benchmark、暂定假设。

## 三、三档预算

正式方案建议给三档：

| 档位 | 定义 | 适用 | 不能牺牲 |
|---|---|---|---|
| Lean | 最小可行活动 | 钱少、时间短、先试水 | 主目标、合规、安全、核心体验 |
| Base | 推荐方案 | 大多数正式活动 | 主目标、参与价值、必要数据采集、风险预案 |
| Stretch | 增强方案 | 有额外投入依据的项目 | 核心交付质量；年度主场面和传播资产仅适用时采用 |

## 四、回报模型

按活动动机选择，不要全塞：

| 回报类型 | 可证明方式 |
|---|---|
| 票务收入 | 票价 × 售票数，区分早鸟/标准/团购/赠票 |
| 赞助收入 | tier 价格 × 预计赞助数，区分确认和 pipeline |
| 销售线索 | MQL/SQL 数、商机金额、会后会议数、CRM 回填 |
| 渠道订货 | 签约额、订货额、首款比例、回款周期 |
| 品牌资产 | 内容资产、搜索占位、媒体报道、UGC、私域标签 |
| 决策与公共价值 | 对应实际业务/公共目标的决策、合作或服务结果；领导到场与报道仅作过程证据 |

## 五、预算价值架构

高预算、老板过会、乙方提案不要只列明细，先解释价值系统：

| 系统 | 包含模块 | 解决的问题 | 预算占比 | 价值证明 |
|---|---|---|---|---|
| 进入系统 | 邀约、报名、入口、导览、动线 | 用户如何进入体验 |  | 到场质量、投诉下降 |
| 发生系统 | 峰值事件、互动、仪式、内容 | 为什么必须到现场 |  | 参与率、停留、传播 |
| 资产系统 | 影像、UGC、媒体、复盘、CRM | 活动结束后留下什么 |  | 内容数量、线索、报告 |
| 保障系统 | 项目管理、安全、合规、应急 | 怎么保证不翻车 |  | 准时交付、事故率 |

## 六、降级模型

每个方案必须准备降级：

| 触发 | 降级动作 | 保留底线 |
|---|---|---|
| 钱少 | 砍装饰、砍低效物料、降搭建规格 | 保留必要保障、核心目标机制和必要数据采集；主场面仅在承载该目标时保留 |
| 时间短 | 并行审批/供应商/传播，减少定制物料 | 不跳过彩排和合规 |
| 人少 | 缩场地、改邀请制、做高质量小场 | 不硬凑人场 |
| 审批慢 | 准备保守版主题、备选场地、替代物料 | 不碰合规红线 |
| 到场低 | 加强 1v1 邀约、候补池、直播/内容转化 | 不伪造热闹 |

## 七、预算自检

- 分项加总必须等于总额。
- 应急金必须单列。
- 不可砍项必须解释原因。
- 可砍项必须说明砍掉损失什么。
- 乙方方案要区分服务费、第三方费用、可选项和不包含项。

## 策元3计算与现金口径
金额注明币种、含税/不含税及税额、数量、单价、服务费基数、有效期与来源。基础费用小计 + 应急金 = 总预算；不能把已包含应急金的总额再加一次。确认赞助、预计赞助、实物支持分开。按支付时点对账，不用预计收入掩盖预付款缺口。不同档位使用同一基数，收入/成本假设做敏感性分析，不用单点预测假装确定。
确定性检查见validation-contract.md和scripts/check_plan.py；缺报价可以交带假设预算，但不能称已锁成本。

涉及多家报价比较、预算削减或平台导出与报名/到场数据诊断时，按commercial-data-review.md执行对应分支，保留来源与口径。

## 资金时点与成本状态

有预付款、分期、退款或资金依赖时，按币种分别列日期、期初可用现金、已确认到账、到期付款/退款、期末可用现金、依据、责任人。任一时点不足单列缺口；活动总预算未超不等于有钱付款。未到账赞助仅列情景，不抵消确定支出；实物支持不当现金。具体税务口径由财务核，未知不能默认为含税。

每笔成本记录预算预留额、合同承诺额、累计已付额、按条款可退额、已释放预算，注明各字段关系而非全部相加：已付通常属于承诺成本，可退额是条件性回收；取消后的净损失依据合同和实际结算，不用预留金额假称已花。按实际支付/回收时间评估取消与延期，再更新受影响档位。采购验收与资源锁定见scope-and-commercial-boundary.md。
