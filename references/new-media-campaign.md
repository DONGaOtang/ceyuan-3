# 国内媒介、内容与活动承接

活动依赖公开传播、报名获客、达人、媒体、投放、直播或私域时使用。内部闭门活动可不做公开传播。平台角色只是规划假设，应用本项目受众、账号和数据校准；不存在固定“2—4个平台”配额。

## 1. 先选任务，再选渠道

分别定义：知晓/理解/报名/到场/核销或成交/会后关系；选择能触达目标人群且有制作与承接能力的最小渠道组合。一个私域渠道可能已足够。自然、付费、达人/媒体合作、自有与伙伴渠道分别记录，不能混算。

| 渠道 | 可考虑的任务与内容 | 使用前需要验证 |
|---|---|---|
| 小红书 | 搜索/攻略/体验证据/种草、活动信息 | 人群城市匹配、账号与商业合作条件、可用承接路径 |
| 抖音 | 演示/现场短视频/直播/本地兴趣 | 同城匹配、真实观看与转化、落地与核销能力 |
| 快手 | 适配人群的内容、直播、达人关系 | 项目受众是否在场、账号历史、合作与商品能力 |
| 视频号、公众号、企业微信/社群 | 邀约解释、信任材料、报名提醒、直播回放、会后跟进 | 用户许可、账号功能、触达频次、销售责任 |
| 微博 | 公共议题、媒体协同与活动信息 | 是否有真实公共讨论需求，不许把热搜当必需品 |
| B站、知乎、行业垂直内容 | 专业解读、测评、议题讨论、嘉宾内容 | 制作成本、受众、周期和内容深度 |
| 美团/大众点评等本地入口 | 门店/活动信息、预约、评价与到店承接 | 门店资格、可用产品、价格库存、核销与退款 |
| 票务/地图/本地生活号/地方媒体 | 找得到、去得了、买得到、本地解释 | 刊登资格、交通信息、票种与服务承诺 |
| 商会/园区/行业媒体/合作伙伴 | To B定向邀请、可信背书 | 名单适配、合作确认和线索归属 |

不将平台刻板印象当事实；没有受众/账号证据时标候选渠道，先小范围验证。具体产品入口与规则按platform-source-register.md实时核验，历史截图不能代表当前资格。

## 2. 每个选中渠道必须形成一行执行闭环

渠道与类型 | 目标人群及证据 | 本阶段任务 | 核心内容/素材 | CTA | 平台允许的承接路径 | 负责人 | 日期 | 制作/合作/投放成本 | 指标与来源 | 停止/扩量条件

不能只写“发抖音、小红书”。CTA要落到实际可用的主页/表单/预约/票务/门店等路径；不能默认任意外链、评论导流或站外加好友均被允许。当前账号权限未知则准备平台内咨询等待核替代。

## 3. 内容与素材生产

预热：为什么值得来、解决什么问题、真实资源证明、报名；活动中：信息指引、参与内容、直播/拍摄、服务变更；活动后：成果、答疑、回放/资料、核销/销售跟进。
按渠道和资源生成必要内容，不强制每次3—5个短视频或UGC。每个素材有原始来源、规格/比例、制作人、审核人、截止时间、版权/肖像/UGC授权范围、备用素材。AI效果图、概念演示与真实现场素材必须区分。
UGC任务说明用户获益、动作、参与限制、奖品与兑现；不以强制发布或不真实好评作为普通参与前提。平台互动/商业内容规则要核验。

## 4. 达人、媒体与投放

达人先看城市/受众/内容匹配、近期同类作品与合作证据，不只看粉丝。评估异常互动、重复评论、样本选择，异常只作待核信号，不武断断言造假。
合作brief写内容主题、事实边界、交付格式/数量、发布时点、改稿、授权期限、商务标识要求、数据回传、取消和补救。媒体名单区分意向/已确认，不能把未确认报道写成资源。
投放分开列素材制作、达人费用、媒体采买、平台消耗、技术/代理费用；设预算上限、观察窗、停投条件。预测用历史可比数据或显式情景，不承诺固定CPM/CPL和曝光。没有预算不硬加付费投放。
扩大消耗、签约或发布仍需对应用户授权，策划能力不自带执行权限。

## 5. 数据与归因

每渠道内容ID/合作ID/活动ID → 合法可用来源标签/渠道码 → 报名或预约 → 到场/核销 → 有效线索/成交 → 退款与后续。记录跨渠道重复、未知来源、自然/付费；能合规匹配时按业务去重键去重，不能匹配时不报告去重总触达。
平台后台、第三方估计、人工截图与用户自述分开。播放/曝光不等于独立人数；公开赞评不代表完播和转化。媒介归因报表不等于增量因果，详见metrics-flow.md。

## 6. 运行与失败恢复

报名不足：先诊断人群、主张、路径、时间/价格、资源可信度；不能只增加发布量。传播大但到场少：检查城市匹配和承诺；到场多但成交少：检查目标人群、体验和销售承接。记录发现而非自动作因果断言。
负面/信息错误/活动取消：事实核验、责任人、统一更新范围、参与者通知、票务与客服路径、已排期素材停止。未授权不实际群发或停投。
固定交付：媒介选择理由 + 上述执行闭环表 + 素材/合作交接 + 数据字典 + 预算/停止条件 + 未核事项。大项目进附件，小项目按output-contract.md压缩600—900个可见字符，字段合并表达，不必逐字段铺开。仅计划沿用已知顾客群做普通文字邀约时，不为表演核验而要求账号后台登录；涉及未确认的表单/外链/投放/自动触达等具体功能才列对应待核项。

涉及多家报价比较、预算削减或平台导出与报名/到场数据诊断时，按commercial-data-review.md执行对应分支，保留来源与口径。

## 7. 宣称、素材版本与发布回执

高影响宣称用claim_id关联具体产品/SKU/服务、型号/固件或方案版本、测量条件、人群与适用范围、支持资料、审核人及有效条件。功效证据区分原料与成品；个案/术前术后展示核筛选、时间、光线处理等比较条件，获肖像授权不等于效果可证明。演示条件、人工干预和录制降级不得在剪辑中消失。事实不支持时删去或待核，不借专家身份推导保证。未在已核范围的现场问答转指定负责人，后续答复留证。

素材ID对应claim_id、文件版本、权利方、音乐/肖像/商品/IP范围、渠道、地域与期限，分别核现场、直播、回放、二剪、广告和UGC再利用。借展/参展授权不能直接当商业宣传或二创授权。创意定稿锁批准版本与制作依赖；事实、嘉宾身份/职务、产品版本变动后，主持稿、海报、下三分之一字幕、报道、落地页和投放按影响复核。

发布登记内容/版本、账号或合作方、时点、链接/回执、禁发期与解除条件。信息错误或取消时由统一事实负责人发更正版本，列自有、达人、媒体、伙伴、投放、表单/票务/客服全部受影响项，指定撤回/更正动作、执行人、截止和实际确认。无法撤回的记录限制、补充更正与用户通知；不能只改主稿就称全渠道同步。没有外部操作授权只交执行清单，不实际发布或停投。

平台能力证据绑定具体账号、查询日期、功能入口和失效条件；换账号、品类、地区、跳转路径后重新核相关能力。评价征集不以正向评价交换已承诺权益，拒评不影响既有服务；激励安排在使用前核平台当前规则。传播评价按真实沟通目标，报道是否正面不能替代事实准确或承诺兑现。
