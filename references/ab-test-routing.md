# 实验验证路由

验证方法与记录统一见experiment-validation.md，本文件只决定选哪一种。

| 条件 | 选择 |
|---|---|
| 关键假设已有可靠历史证据且风险低 | 可采用并监测，不为仪式新增测试 |
| 样本/时间小，需要发现阻力 | 访谈、可用性测试、话术预演；方向性结论 |
| 有可比人群、随机分流、充分样本与观察窗 | 严格实验，预设指标、护栏、停止与样本依据 |
| 现场链路/设备/服务能力不确定 | 彩排、容量压测、故障演练 |
| 涉及审批、公开口径、危机或不可逆承诺 | 核验与相关责任人预沟通，不随意公开试错 |

不以预算级别机械要求AB，不把两个不同渠道的表现当同条件随机实验。复用实验格式与术语，避免两套表冲突。
