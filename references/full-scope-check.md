# 全案适用性检查

每个维度标通过/失败/未知/不适用并给依据。完整策划与完整方案审查使用；单项任务只查受影响维度。适用范围来自用户需求和原案，不要求所有活动做全部模块。

| 维度 | 核心检查 | 触发后的证据/交付 |
|---|---|---|
| 值不值得做 | 活动是否比其他办法更适合目标 | 主目标、替代方案、停止条件 |
| 受众与利益相关方 | 参与者获得什么，誰有资源/否决权 | 行为、障碍、可观察结果 |
| 创意与表达 | 机制是否服务目标，是否适配文化与场景 | 用户旅程、机制细则、必要叙事 |
| 场地与技术 | 同时容量、动线、天气、电力网络、无障碍 | 场地方资料、供应商确认、备份 |
| 人员与议程 | 人手/工位/嘉宾/主持/搭建是否时间冲突 | 排期、唯一最终负责人、替补、彩排 |
| 报名与票务 | 邀约池、报名、签到、票种、退款与候补 | 漏斗、名单口径、峰值吞吐 |
| 传播与媒介 | 渠道人群、内容、达人、投放和转化是否相接 | 来源证据、媒介计划、承接与归因 |
| 商业与现金 | 总预算、付款时点、确认收入、取消损失 | 预算、现金计划、范围与报价 |
| 赞助与伙伴 | 权益是否冲突、资源是否超售 | 库存、授权、履约证明 |
| 安全与审批 | 现场责任、许可、食品/搭建等适用要求是否核实 | 当地权威规则、专业/场地确认、应急负责人 |
| 体验与服务 | 老幼/无障碍、排队、引导、投诉、退款 | 适用服务安排与升级处理 |
| 数据与证据 | 来源质量、指标口径、跨渠道去重与数据授权 | 指标字典、来源账本、访问范围 |
| 知识产权与素材 | 内容/音乐/肖像/UGC再利用权限 | 授权范围、期限、责任人 |
| 收尾与复盘 | 撤场、结算、失物、退款、数据留存、销售跟进 | 截止日期、责任人、交接与复盘 |
| 变更与恢复 | 人数日期预算变了谁受影响 | 版本、依赖、重算及最终文件同步 |

涉及具体法律/许可时查当地现行权威来源，不把通用模板当专业认证。不能核实的写成责任明确的待核项；影响能否举办的阻断执行状态，不妨碍交付条件式草案。

亲子/未成年人或线上线下混合活动，按scenario-operation-cards.md选择对应操作卡；非命中场景不加载。

## 覆盖与操作交接

先从原需求/原案提取关键要求，再逐项对照上表；不能用表格填满证明原需求无遗漏。业务overlay的数量上限不限制实际风险触发。每个适用专业接口记录：动作/对象、适用依据及版本、核验方、放行前提、交出与接收方、异常停止/恢复、凭证和受影响产物。提案阶段允许待核；缺关键放行证据时不标执行条件已核对。

专业操作读professional-operation-cards.md命中短节，参与服务与物料生命周期读service-fulfillment-cards.md命中短节。资金时点、共享人员池、地域许可、文档语义由人工/专业核验，不纳入check_plan.py已通过的范围。可持续仅在项目目标或规模/重复利用需要时加载。
