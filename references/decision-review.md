# 决策人预演：按需，而不是通用老板审核

Step 9先做质量验收，再由用户按明确版本接受交付；专业执行条件另凭相应证据，三者不能互代。决策人模拟预演只是可选辅助，仅在过会、竞标、资源争取或明确分歧时做。用户逐节点控制见user-decision-gates.md，不依赖加载本文件，也不等同陪练。用户只查预算、复盘或普通方向时无需模拟预演。

## 为什么保留

算术正确不等于能做决策。真实拍板者还需要知道：为什么值得投入、备选是什么、最坏损失、何时停止、需要批准哪项。预演用于发现决策材料缺口，不能代替真人偏好或批准。

## 怎样做

从真实读者中选择1—3个必要角色；最多列5个会改变决定的问题。

| 角色 | 应问的问题 |
|---|---|
| 出资/负责人 | 投入买到什么结果？不做或缩小的代价？最坏损失与停止条件？ |
| 客户/采购 | 为什么选此方案？范围、验收、费用与变更是否清楚？ |
| 执行负责人 | 谁在何时完成哪项？依赖资源是否已确认？失败怎么处理？ |
| 销售/赞助 | 权益与线索是否可交付？谁承接？如何证明？ |
| 参与者 | 为什么值得来？参与是否费力？承诺和体验是否一致？ |

输出仅一张表：问题 | 已有证据 | 待补材料 | 建议决定/条件。未知偏好标未知，不虚构老板意见，不强求正面/负面各三条。真实审批记录与模拟意见分开。
无新增问题时写“未发现新增决策阻断”，不要为了表演再生成一轮反对意见。没有客户决策结果，不报告中标概率。
