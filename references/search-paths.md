# 信息源路由与研究停止条件

先写：本次要决定什么、哪条未知会改变决定、已有证据、搜索范围与预算。按问题选来源，不强制先刷社媒或跨2—3个平台。

| 决策问题 | 首选材料 | 需要补核 |
|---|---|---|
| 业务与历史效果 | 原始报名/CRM/POS/财务表、历史复盘 | 去重、窗口、缺失、实际与目标 |
| 受众为何来/不来 | 实际访谈、问卷、退票/投诉、可读评论 | 样本选择、激励偏差、代表性 |
| 平台能做什么 | 官方产品文档、规则中心、账户实际可用能力 | 发布日期、账号/行业/地区限制 |
| 报价与场地资源 | 有效书面报价、场地方确认、供应商资料 | 含税、数量、档期、失效期 |
| 行业规模 | 统计机构、协会、财报、原始研究 | 样本、定义、地域和时间 |
| 创意机制 | 品牌官方案例、参会者记录、数英/SocialBeta/广告门等案例 | 成功宣传与真实结果区别、失效条件 |
| 政企/专业活动 | 政府/园区/协会、垂直媒体、实际客户名单 | 地域适用性、原始公告与授权 |
| 传播与门店承接 | 账号/投放后台、票务/小程序、门店核销 | 自然与付费、点击与到场、退款、跨渠道重复 |

平台入口和当前核验记录见platform-source-register.md。它是起点，不是每个平台都已可访问或必须使用的保证。
公开网页可直接读取；评论/后台需浏览器或账号时按source-access-and-login-workflow.md。搜索摘要只用于发现来源。公开赞数不能推完播率，平台后台零值示例不能当用户账号数据。

## 研究深度

快速：仅填当前决定的关键缺口。标准：覆盖主目标、资源和最高风险。决策级：追溯关键假设、原始资料与冲突，形成证据账本。
按任务设置合理时间/调用预算，不给所有项目固定搜索次数。关键决定已有足够支持、继续搜索不改变判断或预算用尽时停止；列未决项和影响。信息受限返回条件式判断，不无限搜寻。

## 用户声音抽样

记录查询词、日期/时间窗、排序方式、平台、人群筛选、读取条数、正负/中性数量、去重办法、排除理由。避免只看热门帖/精选评论/购买过的粉丝。品牌稿、投放内容、达人合作与自发用户反馈分开。给出样本局限，不称“全网共识”。

输出逐条绑定来源；信号方向与可信度分别记录。反证没有找到时记录该事实，不把反证当低可信等级。

做访谈/用户测试时按关键差异选招募范围或配额（如首次/复访、报名后退出/已到场），记录招募渠道、激励、拒访与非响应、排除理由；主动找能推翻关键假设的案例。不为凑配额编受访者，也不以少数反例估总体发生率。研究计划与已获得结果分别报告。
