# 工作范围、报价边界、验收与变更

正式提案、乙方交付、招商赞助、跨部门协作必须写边界。没有边界，方案越完整，后续越容易失控。

## 一、工作范围

格式：

| 模块 | 我方负责 | 甲方/用户负责 | 第三方负责 | 待确认 |
|---|---|---|---|---|
| 策划 | 主题、机制、流程、方案 | 业务目标、品牌资料、审批 |  |  |
| 设计 | 主视觉方向、物料清单 | 品牌规范、素材授权 | 设计供应商 |  |
| 执行 | 排期、统筹、现场管理 | 场地/嘉宾/内部协调 | 搭建/AV/摄影 |  |
| 传播 | 内容规划、话术、节奏 | 官方账号权限、审核 | 达人/媒体 |  |
| 复盘 | 数据模板、复盘报告 | 实际数据、销售反馈 |  |  |

## 二、不包含事项

正式提案必须列“不包含”，尤其乙方场景。

常见不包含：
- 第三方采购费用。
- 媒体投放费用。
- 达人合作费用。
- 场地租赁费用。
- 搭建、AV、摄影摄像。
- 政府审批代办。
- 超出轮次的设计/方案修改。
- 活动后长期运营。

不要写得像推责，要写成“本次报价/范围不包含，可按需另行报价或确认”。

## 三、甲方配合事项

按本项目实际控制权选择需要甲方提供的资料；第三方掌握的资料由第三方负责，统筹者追踪。以下为候选：
- 品牌资料。
- 历史活动数据。
- 目标人群名单或邀约池。
- 预算上限。
- 审批人和审批周期。
- 嘉宾、媒体、政府关系。
- 法务、合规、财务对接人。
- 反馈时间。

每项都写截止时间。不写时间等于没有责任。

## 四、报价逻辑

乙方/赞助/招商场景按需写：

| 项目 | 说明 |
|---|---|
| 策划服务费 | 策略、创意、方案、流程、统筹 |
| 执行管理费 | 供应商协调、现场管理、项目管理 |
| 第三方费用 | 场地、搭建、AV、摄影、物料、餐饮 |
| 媒体/达人费用 | 投放、达人、KOL、通稿 |
| 应急金 | 按不确定成本评估并注明基数；10%仅为显式规划假设，不是通用要求 |
| 可选项 | 直播、摄影升级、嘉宾邀约、额外物料 |

预算统一口径：基础费用分项加总 = 基础费用小计；基础费用小计 + 应急金 = 总预算。应急金只计一次，税费与费率基数注明。

## 五、验收标准

| 交付物 | 验收标准 |
|---|---|
| 策划方案 | 模块完整、目标清晰、流程可执行、预算可核对 |
| 执行表 | 时间、地点、负责人、物料、费用明确 |
| 设计物料 | 尺寸、格式、数量、交付时间明确 |
| 现场执行 | 按 Run of Show 完成，异常有记录 |
| 传播内容 | 数量、平台、发布时间、素材格式明确 |
| 复盘报告 | 目标 vs 实际、指标回填、问题与建议 |

验收不等于保证商业结果。商业结果受预算、用户资源、外部环境和执行配合影响，需在方案里写清可控与不可控边界。

## 六、变更机制

先对照user-decision-gates.md的用户确认基线。超出已确认范围的实质变更提交原决定、变化、预算/时间/资源/风险影响与备选修法，待用户决定新增取舍后更新对应版本；已明确授权的具体改动直接执行。用户方案确认与供应商合同变更、外部预订/支付权限分别记录，不互相替代。

必须写：
- 变更提出人。
- 变更影响评估：时间、预算、质量、风险。
- 追加费用规则。
- 截止节点：活动日前多少天后不接受重大变更。
- 紧急变更审批人。

常见判定：
- 主题方向重改 = 重大变更。
- 增加活动环节 = 范围变更。
- 增加物料数量 = 成本变更。
- 延迟反馈导致延期 = 根据约定期限、实际控制权、通知记录和因果影响认定责任，不默认全归甲方。
- 政策/天气/不可控因素 = 双方协商调整。

## 七、取消与延期

大型活动或乙方提案建议写：
- 已发生第三方成本按实际合同和取消条款核验可退范围，不先断言不可退。
- 已完成策划/设计/统筹按阶段验收。
- 延期需重新确认供应商档期与费用。
- 户外、政企、大型活动需明确不可抗力处理。

## 八、边界写法原则

- 清楚，但不敌对。
- 保护交付质量，而不是逃避责任。
- 每个待确认都绑定负责人和时间。
- 每个不包含项都可转成可选报价。

## 九、承诺、供应商与交付关闭

多方协作复用项目状态或同目录的承诺台账：承诺ID、具体内容/数量/范围版本、承诺方与接收方、负责人、前提、截止、证据位置、关联产物、状态。状态用拟议/待核/确认/过期或撤回/履行/异常；口头意向、已签、已付、已交付分开，不能互代。变更后核资金、时间、权益、通知和受影响文件；未实际联系/预订不写确认回执。

采购按实际风险核经营主体、专业资格适用性、同类交付能力、设备/人员可用性、分包及替换安排。报价锁规格、含税口径、交付范围、验收、付款、取消及违约处理；由采购取证、专业方核技术条件、业务方验收。供应商替换须重新核受影响条件，不因价格一致沿用旧验收。

借展/高价值原件记录唯一标识、交接前状态照片、保管人、领还签收、异常隔离和约定赔损范围；普通物料不强制逐件建档。婚庆等日期稀缺资源把档期、人员/设备ID、供应商接单回执关联订单，未锁定不得承诺。每项异常说明修复、补偿或争议升级、接手者、期限与关闭凭证；改为“完成”需接收方验收证据，不能仅凭负责人自报。
