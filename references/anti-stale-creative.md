# 反陈旧审查与破常规组合

本文件解决一个问题：活动为什么会越写越旧。大模型默认会回到行业平均答案，所以必须用强制组合和反模板门禁逼它离开常规。

## 一、陈旧活动判定

命中任一条，高风险陈旧：
- 只换主题名，不换用户行为机制。
- 只有视觉包装，没有现场动作。
- 去掉包装后只剩签到、讲话、抽奖、合影。
- 用户没有非来不可的理由。
- 依赖线下参与却没有相应参与价值（线上按线上体验判断）。
- 有传播目标却没有适合的平台内容。
- 有可靠反证却没有回应其揭示的参与障碍。

判词：
- `通过`：机制、动作、传播、验证都成立。
- `修改后通过`：有新意但缺一个关键承接。
- `重做关键机制`：方向有价值，但不能解释目标收益或缺乏必要承接。
- `淘汰`：只是旧流程换皮。

## 二、反陈旧 7 问

按活动目标选择适用问题；熟悉但有效的基线可保留：

| 问题 | 判断标准 |
|---|---|
| 最像哪种旧套路 | 指出具体旧套路，不许写“暂无” |
| 用户是否见过 | 若见过，必须说明差异机制 |
| 去掉包装还剩什么 | 如果只剩流程名称且无法解释目标收益，补机制；熟悉形式不自动失败 |
| 非来不可理由 | 稀缺、身份、收益、关系、体验至少命中一个 |
| 只能现场发生动作 | 判断参与是否有收益；线上和闭门活动不要求线下唯一画面 |
| 平台传播画面 | 需要公开传播时检查所选渠道；不要求默认选社媒 |
| 反向信号/空白/跨界 | 按现有证据选择，不强制跨界或负面信号 |

## 三、六类破常规组合

按任务需要选择下列组合，不强制凑齐6类。

| 组合方向 | 公式 | 产出要求 |
|---|---|---|
| 用户吐槽反转 | 用户讨厌点 × 反向设计 | 把尴尬、无聊、麻烦、假大空反过来 |
| 跨界移植 | 同一动机 × 不相关行业机制 | 借游戏、综艺、宗教、餐饮、剧场等机制 |
| 平台玩法改造 | 活动锚点 × 平台有效玩法 | 把流行玩法改成该活动独有仪式 |
| 感官异常 | 活动目标 × 非视觉感官 | 用声音、气味、触感、味觉制造记忆点 |
| 权力关系反转 | 主办方说教 → 用户决定/解锁/共创 | 让参与者推动活动发生 |
| 时间结构打破 | 单日活动 → 连续任务/倒计时/分章节揭晓 | 把一次性活动变成可追更过程 |

## 四、创意闪卡增强格式

| 字段 | 写法 |
|---|---|
| 创意名 | 8-12 字，能被复述 |
| 常规做法 | 这个类型通常怎么做 |
| 为什么陈旧 | 用户为什么可能无感 |
| 破常规公式 | 六类组合中的哪一种 |
| 一句话概念 | 这场活动到底有什么不同 |
| 现场动作 | 至少一个互动、仪式、体验或内容动作 |
| 传播画面 | 用户拍什么，平台用户为什么停 |
| 解决的动机 | 对齐 Step 2 主判据 |
| 待验证假设 | 用户会因为什么报名/转发/留资/到场/购买 |
| 最小实验 | 预检或 AB 方式 |
| 最大执行风险 | 预算、合规、供应商、现场秩序等 |

## 五、例子

普通发布会：
- 常规：领导致辞、产品介绍、媒体提问。
- 破局：权力关系反转。
- 新机制：观众投票解锁发布顺序，关键模块由用户选择先看什么。

普通招商会：
- 常规：政策宣讲、样板案例、最后签约。
- 破局：时间结构打破 + 游戏机制。
- 新机制：按区域数据生成“城市战队”，现场争夺独家政策包。

普通年会：
- 常规：领导讲话、节目表演、抽奖。
- 破局：用户吐槽反转。
- 新机制：员工用证据争夺年度叙事权，把“领导总结”反转为“员工审判年度关键词”。

## 六、禁止项

- 禁止只给主题名。
- 禁止把跨界行业照搬到活动现场。
- 禁止为了新奇牺牲主判据。
- 高难度先尝试降级；关键条件不可满足时可停止该版本。
- 禁止把“视觉高级”当作创意机制。
