# 条件触发的现场操作卡

只加载命中场景。早期方案列关键岗位、阻断和待核；执行附件填写真实负责人、接手人、触发条件、动作、记录和复验。岗位表不证明人员具备资格；不凭模板设安全比例、天气阈值或法律要求。

## 亲子与未成年人参与

触发：儿童参与、家庭分组、看护交接或可识别儿童素材。先明确儿童年龄/参与限制、成人是否全程陪同、主办方承担何种照护，不能把普通体验默认为托管。

| 环节 | 具体操作 | 核验记录/停止条件 |
|---|---|---|
| 报名与入场 | 家庭ID关联同行成人/儿童，记录必要联系和实际人数；年龄、材料适配、特殊服务由负责人核实 | 姓名等必要资料限制访问；家庭数、总人数、工作人员分别计数，不按家庭数核场地容量 |
| 轮转与照护 | 明确同行责任；转场按家庭核对，不让工作人员兼任相冲突的拍摄/安全岗位；单台与全流程吞吐都算 | 每轮实到/退出记录。体验做不完时改约束并告知，不用盖章冒充完成 |
| 人员分离/走失 | 发现者立即通知指定现场协调人；按已核场地应急流程核对最后位置、家庭ID及联系方式，由指定人员查找和联络 | 暂停受影响活动与非必要流动，保持疏散通道；不自行封堵出口或公开儿童个人资料。需外部应急支援时由指定人按已核流程联络；负责人接手并记录时间 |
| 重聚与离场 | 核对授权接领关系，不仅凭口头自称放行；重聚由负责人确认记录。正常离场、提前退出分别登记 | 照护/接送关系无法确认时暂停交接并升级负责人；普通成人陪同活动也应核实际离场人数 |
| 拍摄与使用 | 参与与宣传选择分开，采集前确认适用许可与意愿；明确不拍摄标识/区域，不削减拒绝者体验 | 发布前按家庭ID核适用素材授权、用途/渠道/期限；撤回联络、保留/删除责任明确。不声称已获实际授权 |
| 天气与备选 | 雨备重新核总人数、布局、服务能力、转移路线与可用时间；出发前和现场的停办决策人分别明确 | 不能全体转入的备选不叫可用雨备；无已核可行安排则延期/取消。通知、退款或改期、物料撤收同步处理 |

执行前用一组家庭走完报名—入场—轮转—退出，再桌面演练人员分离与天气切换。记录谁发现、谁接手、谁通知、何时恢复；没有真实演练就写计划，不填已完成。

## 线上线下混合互动

触发：线上与线下均为服务对象，尤其有问答、投票、预约或嘉宾连线。只是留档录制时不强加双端互动。

| 环节 | 具体操作 | 核验记录/降级 |
|---|---|---|
| 双端承诺 | 分别写线上/线下可获得的内容、互动及会后材料；不能用线上报名数代替观看/到场 | 报名、实际连接、线下签到分别计数；跨端无匹配键不报去重总人数 |
| 岗位与问题队列 | 明确线下主持、线上管理员、技术负责人及最终决策人；两端问题进入同一可操作队列，说明收集、排序、读题、限时和未答后补规则 | 兼岗必须核同时任务是否冲突。线上无法提问不能仅因直播有画面判为体验正常 |
| 排练 | 两端实际测试声音、屏幕、字幕/访问支持、提问路径、延迟及备用联络；切换时谁发令、谁切设备写入Run of Show | 留测试设备、时间、结果及未解决项；没有测试结果只标待核 |
| 断流/嘉宾掉线 | 技术负责人诊断，主持切换不依赖连线的环节；线上管理员通过已获准渠道通知，给下一次状态更新时间。是否暂停全场由指定决策人按事前约定判断 | 故障起止、受影响人群、已答/待答问题保留；不虚构通用恢复时限，按服务承诺约定 |
| 恢复与补交 | 恢复后向两端同步断点；遗漏互动、回放/资料、试用或票务权益逐项安排补交、改期或退款评估 | 负责人、期限、真实发送/交付回执闭环；有录播不等于所有互动权益已履约 |

输出只增加本项目需要的岗位/切换表及未核条件，不复制整份卡。外部通知、发布、退款、后台操作仍按任务授权执行，规划不是已执行。
