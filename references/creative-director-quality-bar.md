# 创意质量检查

只在创意生成、比较或审查时用。先定义目标与硬约束，再探索不同机制，最后收敛；不限制为固定候选数量。

| 维度 | 判断 |
|---|---|
| 有用 | 是否给目标受众可理解的参与收益 |
| 适配 | 是否匹配品牌、人群、场域、预算、资源与目标 |
| 行为 | 谁在何时做什么，如何降低阻力 |
| 差异 | 和常规方案相比改善什么；常规有效基线可以保留 |
| 证明 | 用什么事件/数据判断发生，哪些仍是假设 |
| 执行 | 团队是否知道规则、物料、人员、时间和失败处理 |
| 表达 | 是否容易理解与复述；不强制特定命名字数 |

仅公开传播目标增加内容画面、平台表达、素材授权与制作成本；仅线下独特体验增加现场不可替代性；仅品牌提案增加专属性与资产延展。普通技术培训不因可复用或不适合拍照而不合格。

必要资产按项目选择：命名、视觉方向、邀请/现场文案、拍摄与剪辑、导视、执行转译。概念示意不是设计成稿；需要采购制作的规格由场地与供应商确认。

比较时可逐项给高/中/低与证据，或按用户指定方式评分，但分数不决定可执行或能中标。失败条件按adversarial.md处理；输出状态按output-contract.md。
