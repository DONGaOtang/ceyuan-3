# 报价、预算与实际传播数据诊断

作为module或retro的按需分支，完整策划仅在有相关材料时调用。外部工具不可用时读用户导出文件；不声称已经连接后台。

## 多家报价对比

先统一城市/日期、数量规格、服务时长、币种税费、运输搭拆、版权使用、取消条件与报价有效期，再逐项比较。缺项标未知，不补成0；套餐拆不开时保留套餐，不强行摊价。低价不等于同等交付下更便宜。

固定结果：可比项差额表、包含/缺失范围、付款里程碑与现金缺口、待核事项、推荐及其成立条件。每个金额指向报价单原位置。供应商可用性仍需实际确认，推荐不等于预订。

## 预算压缩

从核对后的总预算出发，记录目标上限或削减比例；先检查已签不可退费用、最低交付约束、基本保障和主目标链路。逐项给保留/减量/换规格/删除、节省金额及依据、体验或效果损失、关联改动。没有报价依据的节省写区间或未知，不凑目标。

固定结果：原总额、调整后总额、已确认节省、待报价节省、距目标差额、损失与风险。另列应急金和付款时间。调整后重算预算、库存、吞吐、排期；目标不可达就说明约束冲突。效果损失没有试验依据时只作假设。

## 国内媒介实际数据诊断

读取适用渠道的官方导出与报名、签到、核销或CRM资料；微信/视频号、抖音、小红书、快手、微博、B站、美团点评按任务选择，不要求凑平台。动态字段定义、归因窗口、权限在采用时核验官方文档或后台说明并记录日期。

1. 建字段映射：文件/导出时间、平台、账号/活动ID、时区、统计窗口、付费/自然/达人、指标定义、去重键。校验空值、重复行、退款、取消、迟到回传及跨期；缺失不当零。
2. 分清曝光次数、触达人数、点击次数、报名人数、到场人数、核销/成交人数。不能用次数冒充人数；不同平台UV不直接相加。只有合法可用且定义一致的关联键才做个人级联结，否则只做分渠道汇总并标不可去重。
3. 在同口径/窗口/人群内算点击率、报名转化、到场率、获客成本等适用指标。分母为0时写不可计算。获客成本说明费用范围，成交额扣退款口径单列。平台归因成交不能直接声称由活动新增。
4. 用同口径历史基线或对照定位瓶颈；无基线只报现状。异常率先核样本和联结方法，不直接推断内容无效。没有对照不输出增量ROI。

固定结果：数据可用性、漏斗及分母、最主要流失点/未知点、费用与结果、归因限制、下一轮可验证动作。每条动作说明假设、最小试验、观察窗口、判据；没有数据不写行业均值占位。

验证次序：先用已有真实方案和导出做回放，记录漏检/误报、人工修正次数及耗时；相同样本、相同任务比较版本。再决定是否拆成独立skill。规则具备不等于市场效果已验证。
